## 术语表

| 术语 | 缩写 | 解释 |
|---|---|---|
| 字典 | Dict | 键值对形式的可枚举业务常量(法规分类、状态、AI 拆分类型等) |
| 字典分类 | DictType | 字典的分组(树形结构),可停用/启用 |
| 字典项 | DictItem | 字典分类下的具体取值 |
| 角色 | Role | 一组权限的集合,授予用户后用户获得这些权限 |
| RBAC | Role-Based Access Control | 基于角色的访问控制 |
| 预置分类 | Preset DictType | 字典首次进入时由系统自动注入的初始数据(如"法规分类") |

## 快速开始

> 这一节回答"我是新来的系统管理员,5 分钟内要做哪 3 件事?"。

### 第 1 件事:看一眼字典管理长啥样

1. 打开系统管理 → 字典管理
2. 看到左侧是字典分类树,右侧是字典项列表
3. 左侧默认有 3 个预置分类:法规分类 / 法规状态 / AI 拆分

### 第 2 件事:创建一个新字典分类

1. 在字典管理页,左侧树顶部的「新增分类」按钮
2. 填名称(如"风险等级")
3. 点「保存」

### 第 3 件事:在新建的分类下加一个字典项

1. 点刚创建的"风险等级"分类
2. 右侧顶部「新增字典项」
3. 填名称(如"高风险")、值(如"HIGH")、排序(如 1)
4. 点「保存」

> 💡 提示:3 件事做完约 3 分钟。完成后你已经会本系统 80% 的字典操作。

## 任务卡

### 任务卡 1:创建字典分类

> ⚠️ **操作前必看**
> - 你需要是"系统管理员"角色
> - 分类名称全局唯一,不能跟已有分类同名(改了之后不能合并)
> - 创建后,字典项可以立即添加,但**分类不能删除**(只能停用)
> - 名称 ≤ 30 字,代码 ≤ 50 字(只允许字母数字下划线)

**适用角色**:`sys_admin`
**前置条件**:已登录 GRC-ONE 平台
**入口**:`系统管理 → 字典管理`,对应后端 `POST /api/sys/dict-types`

#### 步骤

1. 打开系统管理 → 字典管理[SCREENSHOT: dict-list.png]
2. 左侧分类树顶部的「新增分类」按钮[红框:点这个按钮](dict-add-type-btn.png)
3. 填名称(如"风险等级")[看到:输入框获得焦点,光标闪烁](dict-add-type-form.png)
4. 填代码(如"RISK_LEVEL")[SCREENSHOT NEEDED: dict-add-type-form.png]
5. 点「保存」[红框:点这个保存](dict-save-btn.png)
6. 看到左侧分类树刷新,新增的"风险等级"出现在列表里

#### 成功后看到

- 左侧分类树顶部出现新分类
- 右侧字典项列表清空(因为新分类还没字典项)
- 浏览器顶部 toast 提示"保存成功"

#### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 名称 | 输入框 | 是 | 中文,≤ 30 字,用户看到的名字 |
| 代码 | 输入框 | 是 | 英文,只允许字母数字下划线,系统内部标识 |
| 描述 | 多行文本 | 否 | 选填,说明这个分类的用途 |
| 排序 | 数字 | 否 | 默认 0,数字小的排前面 |

#### 如果你卡住了

- **Q: 点「保存」没反应?**
  A: 看屏幕右下角网络图标 — 红色断线是网络问题;否则看表单红字,定位到具体字段。
- **Q: 提示"代码已存在"?**
  A: 换一个代码(如加后缀 `_V2`),或在「字典管理」列表搜该代码,确认是否已建过。
- **Q: 提示"权限不足"?**
  A: 找你的角色管理员申请「字典管理」权限。

### 任务卡 2:在某个分类下添加字典项

> ⚠️ **操作前必看**
> - 字典项的名称 + 值组合全局唯一
> - 值字段是业务系统引用的标识,**改了会导致已有数据找不到字典项**
> - 排序数字小的排前面
> - 同一个分类下的字典项数量建议 ≤ 50

**适用角色**:`sys_admin`
**前置条件**:已有字典分类(如"风险等级")
**入口**:`系统管理 → 字典管理 → 选中分类 → 右侧「新增字典项」`,对应后端 `POST /api/sys/dict-items`

#### 步骤

1. 左侧分类树点"风险等级"分类[看到:右侧字典项列表清空](dict-select-type.png)
2. 右侧顶部「新增字典项」按钮[SCREENSHOT NEEDED: dict-add-item-btn.png]
3. 填名称(如"高风险")[SCREENSHOT: dict-add-item-form.png]
4. 填值(如"HIGH")
5. 选填排序(如 1)
6. 点「保存」
7. 看到右侧字典项列表出现新项

#### 成功后看到

- 右侧字典项列表顶部出现新项
- 浏览器顶部 toast 提示"保存成功"
- 业务系统(FR / LG / ES 等)刷新后,「风险等级」下拉选择里出现"高风险"

#### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 名称 | 输入框 | 是 | 用户看到的名字,如"高风险" |
| 值 | 输入框 | 是 | 业务系统引用的英文标识,如"HIGH" |
| 排序 | 数字 | 否 | 数字小的排前面,默认 0 |
| 状态 | 下拉选择 | 否 | 默认"启用",可改"停用" |

#### 如果你卡住了

- **Q: 提示"值已存在"?**
  A: 在同一分类下换一个值,或搜该值确认是否已有同名字典项。
- **Q: 业务系统下拉里没出现新项?**
  A: 让业务用户刷新页面,或等 5 分钟(前端有缓存)。如果还没出现,看 [任务卡 1:创建字典分类](#任务卡-1创建字典分类) 的"操作前必看"。

### 任务卡 3:停用一个字典分类

> ⚠️ **操作前必看**
> - 停用后,业务系统下拉里**不再显示**该分类下的字典项
> - 已有的业务数据保留(不会丢),只是不可再选
> - 可以重新启用,操作可逆
> - 如果分类下还有字典项,会**一起停用**

**适用角色**:`sys_admin`
**前置条件**:已有字典分类,且有"启用"状态
**入口**:`系统管理 → 字典管理 → 左侧分类树 → 点分类旁的「停用」图标`,对应后端 `POST /api/sys/dict-types/{id}/disable`

#### 步骤

1. 打开字典管理
2. 找到要停用的分类(左侧树)[红框:点分类旁的停用图标](dict-disable-btn.png)
3. 弹窗确认:「确认停用 X 分类?」
4. 点「确定」[看到:分类图标变灰](dict-disabled-state.png)
5. 看到列表里该分类状态从"启用"变"停用"

#### 成功后看到

- 分类图标变灰
- 状态列从"启用"变"停用"
- 业务系统(FR / LG / ES 等)刷新后,该分类下拉消失

#### 字段说明

(本任务卡无新字段,操作的是现有分类)

#### 如果你卡住了

- **Q: 停用按钮是灰的?**
  A: 该分类已经是停用状态,无需再停用。如要启用,看 [任务卡 5:重新启用字典分类](#任务卡-5重新启用字典分类)。
- **Q: 停用后业务系统还有下拉选项?**
  A: 业务用户刷新页面,或等 5 分钟。如果还显示,检查该业务系统的下拉是不是直接读数据库(可以查后端日志看 `select * from dict_item where type_id=X and status='active'`)。

### 任务卡 4:修改字典项

> 💡 提示:**改"名称"是安全的,改"值"会有数据引用风险**。先看下面"操作前必看"。

> ⚠️ **操作前必看**
> - 改"名称" → 业务系统的下拉显示文字会变,数据引用不变 ✓ 安全
> - 改"值" → 业务系统的下拉值会变,**已有数据中的值会找不到对应字典项** ✗ 风险
> - 改"排序" → 只是显示顺序变,数据引用不变 ✓ 安全
> - 改"状态" → 启用 / 停用切换,业务系统下拉会出现 / 消失

**适用角色**:`sys_admin`
**前置条件**:已有字典项
**入口**:`系统管理 → 字典管理 → 选中分类 → 右侧字典项 → 行末「编辑」按钮`,对应后端 `PUT /api/sys/dict-items/{id}`

#### 步骤

1. 找到要修改的字典项[红框:行末编辑按钮](dict-item-edit-btn.png)
2. 点「编辑」
3. 改名称(推荐,安全)
4. ❌ **不要改"值"**——除非你确认没有业务系统引用该值
5. 点「保存」

#### 成功后看到

- 字典项列表刷新,显示新名称
- 业务系统下拉里同步显示新名称(刷新生效)

#### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 名称 | 输入框 | 是 | 用户看到的名字 |
| 值 | 输入框 | 是 | 业务系统引用的英文标识(**谨慎修改**) |
| 排序 | 数字 | 否 | 数字小的排前面 |
| 状态 | 下拉选择 | 否 | 启用 / 停用 |

#### 如果你卡住了

- **Q: 改了值,业务系统下拉找不到字典项?**
  A: 改回去。如果业务数据已经存了新值,需要更新数据库(找 DBA 帮忙跑脚本,慎用)。
- **Q: 编辑表单的"值"字段是灰的?**
  A: 系统设计:值字段创建后**不可修改**(保护业务数据完整性)。如要修改"值",先停用旧项,再创建新项。

## 故障速查

> 场景化组织,按问题类别分小节。

### 权限类(看到 403 / 菜单消失 / 按钮变灰)

**症状**:点「新增分类」按钮是灰色的
**可能原因**:角色未授予 / 临时权限过期 / 多角色冲突
**先试这步**:退出登录重新登录(刷新 token)
**还不行找谁**:你的角色管理员

**症状**:提示"权限不足"
**可能原因**:当前账号没被授予"系统管理员"角色
**先试这步**:查「用户管理 → 选中自己 → 角色」,看是否有"系统管理员"
**还不行找谁**:找人事 / 角色管理员

### 网络类(看到 5xx / loading 转圈 / 超时)

**症状**:保存字典分类时一直转圈,30 秒后报错
**可能原因**:后端服务不可达 / 数据库连接池耗尽
**先试这步**:看浏览器右下角网络图标,再访问 http://localhost:5173/health(返回 200 = 后端正常)
**还不行找谁**:IT 运维(贴报错截图 + 时间)

**症状**:列表加载很慢(> 5 秒)
**可能原因**:字典项数据量大 / 网络慢
**先试这步**:在「字典管理」左侧选具体分类,而不是看全部分类
**还不行找谁**:IT 运维

### 数据类(看到数据错乱 / 找不到)

**症状**:新建的字典项在业务系统下拉里看不到
**可能原因**:前端缓存未刷新 / 字典项状态是"停用"
**先试这步**:业务系统刷新页面 / 5 分钟后看
**还不行找谁**:IT 运维

**症状**:字典项的名称显示乱码
**可能原因**:录入时复制粘贴了带 BOM 的字符
**先试这步**:重新输入名称(不要复制粘贴)
**还不行找谁**:IT 运维

### 操作类(操作没生效 / 报红字)

**症状**:点「保存」按钮没反应
**可能原因**:表单字段有红字(校验不通过)
**先试这步**:看红字提示,定位到具体字段,补齐或修正
**还不行找谁**:见任务卡的"如果你卡住了"

## 常见问题

> 按问题类别组织,每条"症状 → 原因 → 解法"。

### 权限类

**Q: 我是系统管理员,为什么看不到「字典管理」菜单?**
A: 系统管理员默认有字典管理权限。检查:1) 重新登录(刷新 token);2) 看「用户管理 → 选中自己 → 角色」是否真授予了"系统管理员"角色;3) 联系 IT 运维看后端日志。

**Q: 我有「字典管理」权限,但操作时提示 403?**
A: 可能是临时权限过期。在「用户管理 → 我的 → 临时权限」查有效期。

### 数据类

**Q: 字典管理列表加载不出来,一直转圈?**
A: 看浏览器右上角网络图标 — 红色断线 = 网络问题。再看后端日志 `tail -f /var/log/grc/app.log | grep ERROR`。

**Q: 搜索"高风险"搜不到?**
A: 字典项搜索是按"值"字段(英文)搜,不是按"名称"(中文)搜。试试搜"HIGH"。

**Q: 字典项状态显示"停用"但我刚创建?**
A: 创建后默认启用。如果显示"停用",可能是导入脚本或他人改了。查「操作日志」。

### 操作类

**Q: 创建字典分类后能不能改名?**
A: 可以,看 [任务卡 4:修改字典项](#任务卡-4修改字典项)。注意"代码"字段创建后不可改。

**Q: 删除一个字典分类后,引用它的业务数据会怎样?**
A: 字典分类**不能删除**(只能停用)。已有的业务数据保留,只是下拉里看不到该字典项。

**Q: 批量导入字典项怎么操作?**
A: 本系统暂不支持批量导入。如有需求,联系 IT 运维提工单。

## 附录 A:错误码速查

> 6 列硬结构,按 HTTP 状态 + 业务错误码组织。

| HTTP 状态 | 业务错误码 | 症状 | 原因 | 解法 | 找谁 |
|---|---|---|---|---|---|
| 400 | VALIDATION_FAILED | 表单提交,后端返回 400 | 字段校验不通过(必填 / 长度 / 格式) | 看红字提示,定位字段 | 任务卡的"如果你卡住了" |
| 401 | UNAUTHORIZED | 跳到登录页 | token 过期 / 失效 | 重新登录 | IT 运维 |
| 403 | PERMISSION_DENIED | 按钮变灰 / 操作时 403 | 角色权限不足 | 申请权限 / 找角色管理员 | 角色管理员 |
| 404 | DICT_TYPE_NOT_FOUND | 操作某分类报 404 | 分类已被删除 / 链接错误 | 刷新页面 / 找 IT 查后端 | IT 运维 |
| 409 | DICT_TYPE_CODE_DUPLICATE | 提示"代码已存在" | 同名代码已建过(可能停用状态) | 换一个代码 | — |
| 409 | DICT_ITEM_VALUE_DUPLICATE | 提示"值已存在" | 同分类下同名值已建过 | 换一个值 | — |
| 500 | INTERNAL_ERROR | 服务异常 | 后端 bug | 看后端日志 + 报错截图 | IT 运维(贴时间) |
| 503 | SERVICE_UNAVAILABLE | 一直 loading 后报错 | 后端服务挂了 | 等 5 分钟再试 | IT 运维 |
